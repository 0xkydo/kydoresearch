# Task: minimize f(x, y)

Subject area: 2D quadratic optimization (a stand-in for a real research space).

The global minimum of `f(x, y) = (x-3)^2 + (y+1)^2` is 0 at `(3, -1)`.
Contestants do not know the target coordinates a priori; they must run
experiments (edit params, benchmark, observe score) to converge.

Rules:
- Only `src/solution/` is editable.
- `algorithm` must name the approach used (public in submission notes).
- Scores are compared against the current promoted best; only improvements are promoted.
